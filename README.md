I'm building **Fralen CRM**, a web-based platform designed to help optical retailers organize their business operations through a centralized dashboard.

### ✨ Project Highlights

* 🛍️ Product management and inventory-related workflows
* 🔐 Firebase Authentication
* ☁️ Cloud Firestore integration
* 🎨 Custom navy-and-amber design system
* 🌐 Public landing page and SEO foundations
* 📈 A foundation for expanding optical retail management features

**Tech used:** HTML · CSS · JavaScript · Firebase
